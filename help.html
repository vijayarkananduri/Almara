How to use Almara.

Five minutes from first open to your first disposable folder. Pick a topic or read top to bottom.

Start here

  1. Download the latest APK from GitHub Releases and open it. If Android asks, allow installs from your browser or files app. It only asks once.
  2. Open Almara. During first setup, allow file access and notifications. Almara reads only the files you allow.
  3. Wait a moment while it builds its index. Your phone’s files stay exactly where they are.
  4. You land on Home, with a calendar. That is where most people begin.
The idea in one line: you don’t organize anything. You look at your files through a filter, then let the filter go.

Calendar

The heatmap shows how many files landed on each day of the month.

  1. Use the arrows beside the month name to move between months.
  2. Stronger color means more files that day. The bar under the grid shows the steps: 0, 1 to 3, 4 to 10, 11 to 25, 26 and up.
  3. Tap a day. The calendar squeezes up and that day’s files take the whole screen.
  4. A small date badge floats on the left or right. Scroll the list freely, then tap the badge to bring the calendar back.
Know you got it this week but not which day? Look for the strong colors, tap, and scan. It is faster than guessing a name.

Search

Tap the magnifier in the bottom bar.

  1. Type part of a file name in “Search your files”, then tap Search.
  2. Each result shows its source, date and size. Tap the three dots beside a file for actions such as sharing.
Some apps save files with long random names. For those, use the calendar or a folder filter instead of the name.

Make a virtual folder

A virtual folder is a saved rule, not a copy. The files stay where they are.

  1. Tap the plus button, bottom right.
  2. Choose sources: All, WhatsApp, Telegram, Camera, Screenshot, Download or Other. Tap More to see them all.
  3. Choose file type: Images, Videos, Audio, PDFs, Docs, Archives or Other.
  4. Time range: Today, This week, This month or a Custom range.
  5. Give it a name. Under Advanced settings you can also set “Name contains” and an expiry.
  6. Watch the “matching files” count at the top change as you tap. Happy with it? Tap Create folder.

Make a folder for the moment you need it. When you are done, let it expire.

Manage your folders

Open the Folders tab. Each folder shows its rule and how many files match. Tap the three dots on a folder for:

  • Open to see its files.
  • Edit filters to change the rule.
  • Timer to set when it disappears.
  • Archive to set it aside.
  • Remove folder to delete only the rule.
Removing a folder never touches your files. Only the view goes away.

Folder timer

Pick an expiry when you create a folder (Never, Keep for a day, Keep for a week), or later from the folder’s Timer option: 1 hour, 1 day or 1 week.

  1. Folders tab, then the three dots on a folder.
  2. Tap Timer and choose when the view should be removed.
  3. Close the dialog. Almara sends a reminder when it is time, if you allowed notifications.
Only the saved folder expires. Original files are never touched.

Settings

  • Appearance: System, Light, Dark or AMOLED. Pick how Almara feels on your phone.
  • Wallpaper colors: use your Android wallpaper palette.
  • Show recent files on Home: an optional file feed under the calendar. Off by default.
  • Local library: shows how many files are indexed. Tap Refresh index after adding lots of new files.
  • Add a specific folder: only for a provider folder that Android keeps separate. Normal storage is scanned for you.
  • Help and Releases open this guide and the download page.

Privacy and permissions

  • No account, no cloud sync, no analytics, and no internet permission.
  • File access lets Almara read the files you allow. It never changes originals.
  • Notifications are used for folder timers.
  • The index and saved views are stored encrypted on your phone.
  • You can read all of it: the source is open under the MIT license.

Questions

Is Almara a file manager?

No. It helps you find things for now. Make a folder, use it, let it go.

Does it delete or move my files?

No. Folders are rules. Removing or expiring a folder removes only the rule.

Why do some files show long random names?

Other apps saved them that way. Find them by date or source instead.

My new files are missing.

Open Settings and tap Refresh index.

Something is wrong or confusing.

Tell me on GitHub Issues. It is one person making this, and every note helps.
