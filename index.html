Your private digital almara

Almara

A calm, offline-first Android file organiser for the things you keep. See your files by day, find them without remembering where they went, and make virtual folders without moving the originals.

Learn how to use itView releases
What Almara does

Less hunting. More finding.

Almara gives your local files a softer, more useful home while respecting where Android already stores them.

Calendar home

See activity in a month heatmap, select a date, and let the calendar gently make room for that day’s files.

Search that remembers

Search by name, source, type, date, size, or a mix of filters when you only remember part of a file.

Virtual folders

Create saved views from rules. Files stay in their original locations; Almara only remembers the view.

Useful file actions

Open, share, convert, extract, or remove a reference from an Almara view without touching the original.

Optional expiry

Give a temporary view a timer. Keep it from the reminder, or let only the saved view expire.

Private by design

No account, cloud sync, analytics, or internet permission. Your index and rules remain on the device.

Help guide

Start with four small moves.

Almara is designed to be understandable without a manual, but here is the quick path.

Allow access

During setup, allow the file access Almara needs. It reads permitted files to build a local index.

Read the calendar

Tap a day in Home. When the list is long, scroll down and the calendar squeezes into the floating date badge. Tap the badge to bring it back.

Make a view

Tap + on Home or Folders. Choose a source, file type, and time range. Tap More when you need specific choices.

Use three dots

Open a virtual folder’s three-dot menu to open it, edit filters, set a timer, archive it, or remove the folder. Original files stay put.

One important promise

Removing a file from an Almara view removes only that reference. Almara does not move, rename, or delete your original files.
